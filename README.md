# ClaudeCode

個人用のちょっとしたスクリプト・ツール置き場です。

## 含まれるもの

- [`今日の3つだけ/index.html`](今日の3つだけ/index.html) — 今日やる3つのタスクだけを決めて、こなしたら達成感を得られるシンプルなToDoアプリ(単一HTMLファイル、localStorageで状態を保存)。
- [`show_datetime.py`](show_datetime.py) — 現在の日時を表示するスクリプト。

## 使い方

`今日の3つだけ/index.html` はブラウザで直接開くだけで動作します。

```bash
python show_datetime.py
```
